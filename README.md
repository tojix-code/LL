# Linked List Lab v3 — Complete DSA Learning Platform

A responsive React + Vite learning application for Singly, Doubly, Circular and Doubly Circular Linked Lists.

## Features
- Node-based linked-list model with `nextId` and `prevId` relationships
- Simulated hexadecimal memory addresses and pointer map
- Step-by-step operation walkthroughs for insertion, deletion, reverse, traversal and other actions
- Search, update, delete by value, sort, duplicate removal, rotate, find middle, Nth from end, palindrome and pair swapping
- Four complete menu-driven C programs with copy/download
- Pointer debugging challenges
- Complexity comparison, MCQ exam centre and local progress tracking
- JSON import/export and undo/redo
- Responsive mobile navigation and reduced-motion support

## Run
Requires Node.js 20 or newer.

```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
Deploy `dist/` to Netlify or Vercel. Build command: `npm run build`; publish directory: `dist`.

## Important notes
- Addresses in the Memory Lab are illustrative simulated addresses. JavaScript does not expose actual object memory addresses.
- The Operations Lab clearly distinguishes available visualizer actions from planned interactive lessons.
- Progress and visualizer state are stored locally in the browser.
